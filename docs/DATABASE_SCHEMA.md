# HisabMitra — Local Database Schema (SQLite / Drift)

_Generated by `dart run tool/gen_database_schema_doc.dart` from `drift_schemas/hisabmitra/drift_schema_v3.json` — schema version 3. Do not edit by hand._

## Conventions

- Primary keys are client-generated UUID v4 strings (TD-02), so rows keep the same id locally and in the cloud.
- Money is `INTEGER` paise in columns named `*_paise` (TD-01). No floating point is used for money.
- Date-times are stored as unix seconds (Drift default).
- Personal tables are local only and hard-deleted. Group tables carry `revision`, `sync_state` and a `deleted_at` tombstone for sync.
- Foreign keys are enforced (`PRAGMA foreign_keys = ON`). Multi-row financial changes run inside one DB transaction.
- Upgrades use step-by-step Drift migrations; user data is never dropped. Each schema version is exported to `drift_schemas/` and covered by `test/drift/hisabmitra/migration_test.dart`.
