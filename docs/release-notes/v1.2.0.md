### HisabMitra 1.2.0 — invite links and live updates

**Join a group with one tap**
- A shared group invitation now has a "Tap to join" link. Tapping it opens
  HisabMitra and joins the group directly — no code to type.
- Not signed up yet? The app remembers the invitation and joins the group
  right after you verify your email.
- If the invitation can't be used (expired, already used, no internet),
  the Join screen tells you why, with the code already filled in.
- Without the app, the link shows the code and a download button.

**Group changes appear by themselves**
- While HisabMitra is open, a new expense, settlement or member added on
  another phone shows up within a second or two — no need to pull down or
  tap sync.
- The same works for your own hisab on your other phone.
